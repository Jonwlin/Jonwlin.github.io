instructions:
  - { text: "Make the multi-purpose marinade: in a large bowl, combine the gochujang, brown sugar, coarse chili powder, cooking wine, dark soy sauce, and crushed garlic and mix evenly." }
  - { text: "Chop the chicken leg into edible sizes." }
  - { text: "Chop the onion into 2 cm pieces. Cut the potato 1 cm thick and into 1 cm strips." }
  - { text: "Cut the cabbage into large pieces." }
  - { text: "Cut the green part of the green onions into 3 cm pieces. Halve the white stalks and cut into 3 cm pieces." }
  - { text: "Wash the garlic and trim the ends." }
  - { text: "Trim the shishito stalks and cut them in half. Chop the hot pepper into small pieces." }
  - { text: "In a large bowl, mix the chicken, potatoes, onions, cabbage, hot pepper, shishito peppers, garlic, and 1 cup of the multi-purpose marinade." }
  - { text: "Once seasoned evenly, mix in the green onions, then the black pepper and sesame oil." }
  - { text: "Plate the marinated chicken and sprinkle with ground sesame seeds." }
  - { text: "In a frying pan, add the marinated mix and cook slowly over medium heat." }
  - { text: "When the marinade starts to burn, add water and stir-fry." }
  - { text: "Use scissors to cut large pieces of chicken into bites." }
  - { text: "Taste, then add the rice cake and cook." }
  - { text: "Parboil the udon in boiling water, drain well, and stir-fry it with the chicken to finish." }
